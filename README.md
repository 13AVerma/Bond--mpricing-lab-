# Bond Pricing Lab

This project is a C++ QuantLib learning project.

The goal is to build a small bond-pricing program from first principles.

## Financial idea

A fixed-rate bond is a contract that pays fixed coupon cashflows on scheduled dates and repays principal at maturity.

The program will:

1. Build a bond schedule
2. Create a fixed-rate bond
3. Calculate accrued interest
4. Build a yield curve
5. Price the bond using a discounting engine
6. Add a credit spread
7. Show how the price changes

## Core pipeline

Date
→ Schedule
→ Bond
→ Cashflows
→ Yield Curve
→ Discounting Engine
→ Price

## Learning goals

- Understand QuantLib objects
- Understand bond pricing
- Understand clean price vs dirty price
- Understand accrued interest
- Understand yield curves
- Understand credit spreads
